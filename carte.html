Notre carte

Pains, pâtisseries et sandwichs à emporter. Prix relevés en vitrine. La carte brasserie complète (plats, boissons) est disponible sur place.

Les produits sont générés à partir d'une structure de données JS partagée entre les pages (js/products.js : tableau d'objets nom / catégorie / prix / image). Cette architecture sépare les données de l'affichage, comme le ferait une base de données, tout en restant compatible avec un hébergement statique (GitHub Pages).
